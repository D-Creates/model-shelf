# Model Shelf

Model Shelf — a private, offline library and inspector for local model files (GGUF and safetensors) on macOS and iPhone. Reads file headers only. No network, no inference.

- Web page: https://dcreations.fr/model-shelf/
- Privacy: https://dcreations.fr/model-shelf/privacy/ (the app collects no data)
- Releases: see the Releases page of this repo. The newest is marked "Latest"; older versions stay available.

## Build
1. Install Xcode 26 and XcodeGen (`brew install xcodegen`).
2. Run `xcodegen generate` in this folder.
3. Open the generated project, set your own signing team, and run.
